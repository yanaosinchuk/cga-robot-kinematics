# Technical report

This directory contains the LaTeX source for the accompanying seminar paper:

**From Ideal Points to Robot Joints — Computational Geometry and Conformal Geometric Algebra**

The report uses the numerical outputs and vector figures generated by the Python reproducibility pipeline.

## Rebuild

From the repository root:

```bash
python src/generate_figures.py
cd paper
latexmk -pdf main.tex
```

The document reads generated numerical macros from:

```text
../results/results.tex
```

and generated PDF figures from:

```text
../figures/
```

The committed PDF is named:

```text
from_ideal_points_to_robot_joints.pdf
```

The numerical experiment uses the fixed random seed `20260922`. Runtime dependencies are pinned in the root `requirements.txt` to keep the reported results reproducible.
